# Olympiad Mathematics in Lean 4

This repository collects formal proofs of mathematical olympiad problems in
Lean 4 using Mathlib, covering IMO, APMO, BMO, and JBMO.

The goal is to build a collection of machine-verified proofs that faithfully
represent the original problems, alongside a reusable library of mathematical
lemmas. Problems are organized by competition, year, and problem number.
